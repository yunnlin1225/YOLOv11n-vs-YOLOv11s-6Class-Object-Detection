# 🚀 YOLOv11n 8-Class Final Deployment
### YOLOv11n 八類別最終部署模型（WildGuard AI 正式版本）

## 📌 1. 模型說明（Model Overview）

本階段為 YOLOv11n 經過前期模型訓練、**5-Fold Cross Validation**、多階段模型優化及資料集擴充後，所建立的 **八類別最終部署模型**。

本研究由前期六類別物件偵測逐步擴充至八類別，最終使用包含 **2,000 張八類別目標影像及 200 張背景負樣本，共 2,200 張影像**的資料集進行訓練，以提升模型在多物種辨識及自然環境監測情境下的應用能力。

為評估不同訓練回合數對模型辨識效能的影響，本階段統一採用 **80% Training / 20% Validation** 資料切分方式，並規劃以下兩組訓練實驗：

- 📊 **100 Epochs：** 使用 100 個訓練回合建立八類別模型，作為模型效能評估與比較的基準。
- 🚀 **第二組 Epochs（待確認）：** 調整訓練回合數，進一步比較模型在 Precision、Recall、mAP50 及 mAP50-95 等指標上的表現。

兩組實驗皆以 **YOLOv11n 八類別模型**為基礎，並採用一致的資料切分與主要訓練設定，以比較不同 Epochs 對模型效能的影響。

最終將綜合模型驗證結果與實際影像、影片推論表現，選擇適合的模型權重，作為 **WildGuard AI 多物種智慧監測與生態風險決策平台的主要物件偵測模型**。

## ⚙️ 2. 最終訓練參數（Final Training Parameters）

YOLOv11n 八類別最終訓練模型的參數，主要延續前期 **5-Fold Cross Validation 與模型優化實驗**所累積的研究經驗，並配合八類別資料集擴充進行設定。

本階段分別採用 **100 Epochs 與 200 Epochs** 進行模型訓練，且兩組 Epochs 均建立 **80% Training / 20% Validation** 與 **100% Full Training** 版本，以比較不同訓練回合數的模型表現。

主要訓練參數如下：

| 訓練參數 | 設定值 |
|:---:|:---:|
| Model | YOLOv11n |
| Classes | 8 |
| Epochs | **100 / 200** |
| Batch Size | 8 |
| Image Size | 640 |
| Workers | 2 |
| Optimizer | Auto |
| AMP | True |
| Cosine LR | True |
| Close Mosaic | 10 |
| cls | **0.75** |
| Seed | 42 |
| Deterministic | True |

其中 **cls=0.75** 延續前期 YOLOv11n 模型優化所採用的參數設定，並作為八類別模型訓練的主要設定。

兩種訓練方式如下：

- 📊 **80% Training / 20% Validation：** 使用 1,760 張影像進行訓練，保留 440 張影像進行模型效能評估。
- 🚀 **100% Full Training：** 使用完整 2,200 張影像進行訓練，不保留獨立驗證集，作為後續實際部署測試的候選模型。

> 100 與 200 Epochs 版本使用相同的主要訓練參數，並分別建立 80/20 與 100% Full Training 模型，以分析訓練回合數對模型效能的影響。

## 📊 3. 80% Training / 20% Validation

為評估 YOLOv11n 八類別最終模型的偵測效能，本階段將 **2,200 張影像資料集**依 80% Training / 20% Validation 進行切分，並分別使用 **100 Epochs 與 200 Epochs** 進行模型訓練，以分析不同訓練回合數對模型辨識效能的影響。

資料配置如下：

- 🏋️ **Training：1,760 張**
- 📊 **Validation：440 張**
- 📁 **Total：2,200 張**

此版本保留 20% 的資料作為 Validation，用於評估模型對未參與訓練影像的辨識能力，並透過 Precision、Recall、mAP50 與 mAP50-95 等指標進行模型效能分析。

### 📈 3.1 100 Epochs 模型評估結果（Evaluation Results）

本階段首先採用 **100 Epochs** 進行 YOLOv11n 八類別模型訓練，作為後續增加訓練回合數之效能比較基準。

#### 📊 整體模型評估結果

| Precision | Recall | mAP50 | mAP50-95 |
|:---:|:---:|:---:|:---:|
| **93.9%** | **90.9%** | **95.5%** | **80.2%** |

#### 📋 各類別辨識結果（Per-Class Results）

| Class | Precision | Recall | mAP50 | mAP50-95 |
|:---:|:---:|:---:|:---:|:---:|
| Dog | 95.2% | 83.8% | 94.5% | 82.1% |
| Cat | 92.7% | 88.6% | 93.4% | 78.1% |
| Bear | 95.3% | 90.3% | 97.3% | 84.5% |
| Pig | 89.6% | 92.5% | 94.9% | 78.5% |
| Monkey | 93.7% | 95.0% | 96.6% | 84.7% |
| Person | 91.7% | 97.4% | 96.8% | 84.6% |
| Iguana | 96.1% | 87.1% | 94.6% | 64.9% |
| Deer | 97.2% | 92.4% | 95.6% | 84.0% |

整體結果顯示，YOLOv11n 在 **100 Epochs** 設定下，達到 **93.9% Precision、90.9% Recall、95.5% mAP50 及 80.2% mAP50-95**。

其中，**Bear 類別的 mAP50 達到 97.3%**，顯示模型在本次驗證集上對黑熊具有良好的辨識表現；而 Iguana 類別的 mAP50-95 為 64.9%，相較其他類別仍有進一步優化空間。

### 📈 3.2 200 Epochs 模型評估結果（Evaluation Results）

為進一步評估訓練回合數對模型效能的影響，本階段將 YOLOv11n 的訓練回合數增加至 **200 Epochs**，並維持 80% Training / 20% Validation 的資料配置。

#### 📋 各類別辨識結果（Per-Class Results）

| Class | Precision | Recall | mAP50 | mAP50-95 |
|:---:|:---:|:---:|:---:|:---:|
| Dog | 93.8% | 81.3% | 93.6% | 81.1% |
| Cat | 97.6% | 91.8% | 94.7% | 75.9% |

然而，Iguana 類別的 mAP50-95 為 59.4%，仍有進一步改善空間。

### 📊 3.3 不同 Epochs 模型比較（Epochs Comparison）

為分析不同訓練回合數對 YOLOv11n 八類別模型的影響，本研究比較 100 Epochs 與 200 Epochs 的整體驗證結果。

| Evaluation Metric | 100 Epochs | 200 Epochs |
|:---:|:---:|:---:|
| Precision | 93.9% | **94.6%** |
| Recall | **90.9%** | 90.1% |
| mAP50 | **95.5%** | 94.1% |
| mAP50-95 | **80.2%** | 79.3% |

比較結果顯示，200 Epochs 的 Precision 由 93.9% 提升至 94.6%，增加 **0.7 個百分點**；但 Recall、mAP50 與 mAP50-95 分別下降 **0.8、1.4 與 0.9 個百分點**。

在黑熊辨識方面，200 Epochs 的 Bear Precision、Recall 與 mAP50 均高於 100 Epochs，顯示延長訓練回合數可能有助於改善特定類別的辨識表現。

整體而言，**100 Epochs 在 mAP50 與 mAP50-95 方面表現較佳，而 200 Epochs 在整體 Precision 及黑熊辨識指標方面具有優勢**。

因此，本研究將保留兩組模型，並搭配後續實際影像與影片推論測試，進一步評估其誤判、漏判及實際應用表現。

此訓練方式將全部影像投入 Training，使八類別目標樣本與背景負樣本完整參與模型訓練。

資料組成如下：

- 🎯 **八類別目標樣本：2,000 張**
- 🌲 **背景負樣本：200 張**
- 📁 **Training：2,200 張（100%）**

兩組模型皆使用完整資料集進行訓練，以分析不同 Epochs 對模型在已提供評估資料上之表現的影響，並作為後續實際部署測試的候選模型。

## ✅ 5. 最終模型說明（Final Model Summary）

YOLOv11n 八類別最終部署模型建立於前期 **5-Fold Cross Validation、模型優化與資料集擴充**的研究基礎上，並使用包含 **2,000 張目標影像與 200 張背景負樣本，共 2,200 張影像**的完整資料集進行模型訓練。

本階段首先採用 **100 Epochs**，分別建立 **80% Training / 20% Validation** 與 **100% Full Training** 兩種模型版本，並沿用一致的主要訓練參數。

其中，**80% Training / 20% Validation** 版本主要用於評估模型的 Precision、Recall、mAP50 與 mAP50-95，整體評估結果達到 **93.9% Precision、90.9% Recall、95.5% mAP50 及 80.2% mAP50-95**，作為模型辨識效能與泛化能力分析的重要依據。

**100% Full Training** 版本則使用全部 2,200 張影像進行訓練，其評估結果達到 **99.2% Precision、99.1% Recall、99.5% mAP50 及 94.0% mAP50-95**，作為完整資料訓練與後續部署測試的候選模型。由於此版本未保留獨立驗證集，其評估結果不直接代表對未見影像的泛化能力。

最終 YOLOv11n 八類別模型負責辨識 **Dog、Cat、Bear、Pig、Monkey、Person、Iguana、Deer** 八個正式類別，並將物件偵測結果提供給 **WildGuard AI 多物種智慧監測與生態風險決策系統**，作為後續風險分析、智慧警示及決策支援的重要視覺辨識資訊。

後續將視模型訓練與實際推論結果，增加不同 **Epochs** 的訓練實驗，進一步比較模型辨識效能與實際應用表現，並選擇適合的模型權重作為正式部署版本。
